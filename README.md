# Arjkb Tap

## How do I install these formulae?

`brew install arjkb/tap/<formula>`

Or `brew tap arjkb/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "arjkb/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
